READAWRITE · LOCAL IMPORT

นำเรื่องและตอนเข้าคลังวิเคราะห์

วางลิงก์ ReadAWrite เพื่อเปิดหน้าต้นทาง แล้วใช้ปุ่มบุ๊กมาร์ก “ดึงเข้าห้องแกะนิยาย” จากหน้าตอนที่คุณมีสิทธิ์อ่าน เนื้อหาจะถูกเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่มี AI/API และไม่มีการส่งต้นฉบับออกไป

ข้อจำกัดสำคัญ: เว็บที่โฮสต์บน GitHub Pages ไม่สามารถอ่านหน้า ReadAWrite ข้ามโดเมนได้เองเพราะนโยบายเบราว์เซอร์ จึงไม่สามารถไล่ทุกตอนจากลิงก์เดียวโดยอัตโนมัติในเวอร์ชันเว็บสแตติกนี้ได้ ให้เปิดแต่ละตอนแล้วกด bookmarklet เพื่อเก็บตอนลงคลัง หากเป็นเรื่องของคุณเองหรือได้รับอนุญาตให้นำเข้าเท่านั้น
