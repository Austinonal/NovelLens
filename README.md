# ห้องแกะนิยาย

เว็บสำหรับดึงตอนนิยายที่คุณเปิดอ่านอยู่ (เช่น ReadAWrite) แล้ววิเคราะห์ฟีล โทน จังหวะ และสไตล์การเขียน พร้อมเทียบร่างของคุณกับต้นฉบับว่าใกล้กันแค่ไหน

**ไม่ใช้ AI, ไม่ใช้คีย์, ไม่ส่งข้อความออกไปไหน** ทุกอย่างคำนวณในเบราว์เซอร์จากไฟล์เดียวคือ `index.html`

## เปิดใช้บน GitHub Pages

1. Push repo นี้ขึ้น GitHub
2. ไปที่ **Settings → Pages** แล้วตั้ง Source เป็น `Deploy from a branch`, `main` / `root`
3. เปิดลิงก์ `https://<username>.github.io/<repo>/`

## ใช้งาน

1. ลากปุ่ม **ดึงเข้าห้องแกะนิยาย** ไปไว้ที่แถบบุ๊กมาร์ก
2. เปิดตอนนิยาย ถ้าเว็บมีโหมดอ่านแบบ html ให้เลือกโหมดนั้น เพราะโหมด canvas เป็นรูปภาพและดึงข้อความไม่ได้ จากนั้นกดปุ่ม
3. แอปจะเปิดขึ้นและวิเคราะห์ให้ทันที
4. ในหัวข้อ **ลองแต่งแนวนี้** ให้วางร่างของคุณ แล้วกด **เทียบกับต้นฉบับ**

## สร้างตัวละครและพล็อต

แท็บ **สร้างตัวละครและพล็อต** ใช้วางโครงนิยายของคุณเอง

1. **ตัวละคร:** กรอกรายละเอียด 5 หมวด คือ ตัวตน, รูปลักษณ์, จิตใจ (นิสัย ข้อเสีย สิ่งที่อยากได้ สิ่งที่กลัว), ภูมิหลัง (ปมในอดีต ความลับ) และอื่นๆ ทุกช่องมีปุ่ม **สุ่ม** เพิ่มตัวละครได้หลายตัว และกำหนดบทบาทได้ (ตัวเอก, คู่, ตัวร้าย ฯลฯ)
2. **พล็อต:** เลือกแนวเรื่อง, โครงเรื่อง (สามองก์, การเดินทางของฮีโร่, คิโชเท็นเค็ตสึ), ความขัดแย้งหลัก, ตอนจบ, จำนวนตอน และฉาก ปุ่ม **ใช้แนวจากผลวิเคราะห์** จะดึงแนวจากนิยายที่เพิ่งแกะมาใช้
3. กด **สร้างพล็อต** ระบบจะเติมช่องที่ว่างให้ แล้วสร้างแก่นเรื่อง, โปรไฟล์ตัวละคร, ความสัมพันธ์ และโครงเรื่องแยกตามตอน
4. กด **สุ่มเหตุการณ์ใหม่** เพื่อลองเหตุการณ์ชุดอื่น หรือกด **คัดลอกเป็นข้อความ** เพื่อนำไปใช้ต่อ

ระบบสร้างจากเทมเพลตเหตุการณ์ของแต่ละแนว (`PLOTS`, `BEATS`, `ENDINGS`) ผสมกับรายละเอียดตัวละครที่กรอก ไม่ใช้ AI ถ้าอยากได้เหตุการณ์หลากหลายขึ้น ให้เพิ่มประโยคในรายการเหล่านั้น ข้อมูลตัวละครจะบันทึกไว้ในเบราว์เซอร์ที่ใช้อยู่

## วิเคราะห์อย่างไร

| ด้าน | วิธีวัด |
|---|---|
| ฟีล / แนวเรื่อง | นับคำอารมณ์จากรายการคำในแต่ละหมวด (`FEELS`) ต่อ 1,000 ตัวอักษร |
| มุมมองการเล่า | นับ ผม/ฉัน เทียบกับ เขา/เธอ ในส่วนบรรยาย (ไม่นับในเครื่องหมายคำพูด) |
| บทพูด | สัดส่วนตัวอักษรที่อยู่ในเครื่องหมายคำพูด |
| ความยาววลี / ย่อหน้า | ตัวอักษรเฉลี่ยต่อช่วงที่คั่นด้วยการเว้นวรรค และต่อย่อหน้า |
| ผัสสะ | นับคำเกี่ยวกับแสง เสียง กลิ่น อากาศ |
| คำที่วนซ้ำ | ตัดคำภาษาไทยด้วย `Intl.Segmenter` แล้วนับคำที่เจอบ่อย ชื่อที่ถูกตัดแยกจะถูกต่อกลับ |
| เนื้อเรื่องย่อ | เลือก 3 ประโยคที่มีคำสำคัญของตอนมากที่สุด เรียงตามลำดับเรื่อง |
| ตัวละคร | คำที่วนซ้ำซึ่งตามด้วยการกระทำ (เดิน มอง พูด ฯลฯ) หรืออยู่ในฉากที่มีบทพูด แล้วอ่านนิสัยจากคำรอบชื่อ (`TRAITS`) |
| อารมณ์ไล่ตามตอน | แบ่งตอนเป็น 6 ช่วง แล้ววัดฟีลทีละช่วง เพื่อหาจุดพีค |
| ระดับภาษา | นับหางเสียง คำหยาบ และคำแบบวรรณกรรม |
| คำปฏิเสธ | คำที่มี ไม่/ไม่ได้/ไร้ นำหน้าจะไม่ถูกนับ |
| ความใกล้เคียง | เทียบแต่ละด้านของร่างกับต้นฉบับ แล้วเฉลี่ยเป็นเปอร์เซ็นต์ |

ถ้าระบบจับแนวหรือนิสัยผิด ให้เพิ่มคำในรายการ `FEELS` หรือ `TRAITS` ที่ส่วนบนของสคริปต์

## ข้อจำกัด

- เรื่องย่อเป็นประโยคที่ดึงมาจากต้นฉบับ ไม่ได้เรียบเรียงใหม่ ส่วนนิสัยตัวละครอ่านจากคำรอบชื่อ ไม่ได้เข้าใจความหมาย ตัวละครที่ถูกเรียกแค่ "เขา/เธอ" จะหาไม่เจอ
- ระบบไม่เขียนเนื้อหาให้
- ปุ่มดึงได้เฉพาะตอนที่คุณเปิดอ่านได้อยู่แล้ว ใช้เพื่อศึกษาส่วนตัว และอย่าเผยแพร่เนื้อหาของผู้เขียนคนอื่น
